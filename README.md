**Лабораторная работа 2**


В данной лабораторной работе, направленной на изучение основ HTML и CSS, было сделано:

Созданы 4 страницы сайта: главная, страница эпох, страница шедевров и страница контактов.
Добавлены ссылки для перехода между страницами в верхнем меню.
Добавлены иллюстрации-обложки на главной странице.
На странице шедевров создана таблица с выравниванием текста слева, по центру и справа.
Оформление вынесено в отдельный файл `style.css`. Использованы селекторы тегов, классов и идентификаторов (id у полей формы).
Для оформления выбраны теплые оттенки: кремовый фон, коричневые рамки и красно-коричневые акценты, связанные с идеей классического искусства.
Сайт называется «История искусств». За основу взята идея образовательного портала об искусстве. В каталоге эпох можно прочитать о разных периодах (от Античности до Модерна) и посмотреть таблицу с самыми известными шедеврами. На странице контактов есть форма для связи.

Сайт написан на HTML и CSS, без JavaScript и библиотек. Данные в таблице шедевров заполнены вручную и не обновляются автоматически.

Все файлы находятся в папке lab2. Чтобы посмотреть сайт, нужно открыть lab2/index.html в браузере.

**Лабораторная работа 3**


В данной лабораторной работе, направленной на изучение основ JavaScript, было сделано:

В папку `lab3` скопирован каркас проекта из репозитория `teach-kirshdv/js-tasks`. Все зависимости установлены через `npm install`.
В файле `src/core.js` реализованы 10 функций, покрывающих различные аспекты языка JavaScript:
- **Работа с числами и побитовые операторы**: проверка на целое число (`isInteger`), определение степени двойки (`isBinary`).
- **Циклы и массивы**: генерация массива четных чисел (`even`), подсчет суммы чисел (`sumTo`), вычисление факториала (`factorial`).
- **Рекурсия**: сумма чисел через рекурсию (`recSumTo`), поиск N-го числа Фибоначчи (`fibonacci`).
- **Замыкания и функции высшего порядка**: создание функции-вычислителя (`getOperationFn`), генератор арифметической последовательности (`sequence`).
- **Работа с объектами**: рекурсивное глубокое сравнение объектов и массивов (`deepEqual`).

Все функции написаны без использования сторонних библиотек. Проверка правильности реализации осуществлялась с помощью встроенных тестов (Mocha). По итогам запуска `npm test` все 16 тестов успешно пройдены (16 passing).

Проект выполнен в ветке `lab3`. Для запуска тестов необходимо перейти в папку `lab3` и выполнить команду `npm test` в терминале.
